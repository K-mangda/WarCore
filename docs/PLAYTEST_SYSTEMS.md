# Phase 2 playtest tools — 2026-11-13

- Pause uses the supplied Inventory / central menu / Stats layout, native exported frame and button art. Resume, Settings, Lab, New Run and local history are connected. Escape resumes; modal keyboard focus is contained.
- End screen follows Damage / Summary / Quests columns and uses Fox portrait. Time/kills/level, weapon, chosen Tomes and collected Gold/Silver come from the current run. Per-source damage totals, DPS, native weapon levels, quests and final currency awards remain explicitly unavailable. No screenshot reward is hardcoded.
- Stats show actual current HP, damage per hit, interval, attack count, Tome levels and effective web bonuses; no invented native stat entries.
- Local history (`warcore.runs.v1`) keeps the newest 30 death/reset runs. Death is finalized once; restart cannot duplicate it, empty runs and page reloads are not recorded. Records clone Tome levels. Storage failure keeps session history; blocked storage is not cloud persistence. History is per browser/origin and can disappear when site data is cleared.
- Controls retain existing defaults and storage key. Five movement/jump actions can be rebound; unique supported physical codes only. Esc/Tab/arrows/1–3 and browser modifier combinations are reserved. Reset restores bindings and existing look settings. Only physically held active-run movement resumes after a modal; typing in menus does not inject movement. No controller support.
- Video presets set only render scale / view distance / FPS cap: Low .6/80/60; Balanced .85/150/Auto; High 1/250/Auto. FOV/camera distance are preserved; manual changes derive Custom. These are web presets, not extracted quality levels. No GPU benchmark claim.
- Lab search filters entities in the current category; category switches clear the search. Existing per-weapon/action selectors remain. Empty results clear the viewport and disable playback. Readiness explains combat-ready, preview-only and missing native behavior; model preview is not advertised as an implemented attack.
- Game initial-load Retry reconstructs/disposes the failed Engine. Lab room Retry retries failed cached dependencies while preserving successful loads; failed GPU-backed view instances are disposed and replaced. Module boot recovery remains separate. No whole-game refresh for room/media failures.
- Both game and Lab show the short Git SHA, CI prefers GITHUB_SHA, local builds resolve HEAD; build timestamp is in the game version tooltip. Existing iframe build nonce remains for cache invalidation.

Unknown original-game data is listed in PAUSE_END_REFERENCE.md and linked from EXTRACTION_BACKLOG.md. The other AI owns extraction. The user owns visual/audio/gameplay review; focused automated checks verify state/persistence/input and build/package behavior, not visual identity.
